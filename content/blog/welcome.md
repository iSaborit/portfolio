Welcome! This is the first post on my brand-new portfolio site, powered by [Zola](https://www.getzola.org/).

## Why Zola?

Zola is a fast, single-binary static site generator written in Rust. It's quick to set up, has no JavaScript runtime dependency, and produces beautiful, minimal output.
