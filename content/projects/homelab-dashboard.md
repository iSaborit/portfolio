A lightweight dashboard that aggregates the status of all my self-hosted services. Built to be fast and unobtrusive.

## Features

- Live health checks for all services
- Docker container overview
- Quick links to key UIs

## Tech stack

- Rust (Axum) backend
- SQLite for persistence
- Minimal HTML/CSS frontend
